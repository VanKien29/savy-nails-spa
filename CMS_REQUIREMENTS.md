# Savy Nails & Spa administration

Public pages: Home, About Us, Services, Gallery, Contact Us. The white/gold reference layout offers contact-only appointments. No public booking form is offered.

Keep Laravel/Filament authorization, users, shared settings, SEO, media processing, navigation, service editor, caching and static preview export. A fresh catalog has 31 approved services in four categories. Re-seeding/cleanup must preserve existing Savy IDs, prices, descriptions, visibility and order.

Use the Savy wordmark, S favicon and configured contact details/hours/socials. Google Maps remains the client-supplied listing and loads near the viewport automatically. The hero is eager; other photos are lazy. Motion respects reduced-motion preferences.

Shared SEO supplies unique metadata, canonical, robots, sitemap, Open Graph and schema. Production is indexable; Vercel export remains noindex. Metadata must identify Savy and Walla Walla.

For an existing installation, use savy:cleanup after uploading the new assets. The command makes a private backup and preserves admin credentials. The explicit --replace-legacy-menu option acts only on a detected old catalog. See SAVY_CLEANUP.md.
