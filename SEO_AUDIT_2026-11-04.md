## Findings and priorities

1. P1 for an official launch: all five pages return `noindex, nofollow` in both meta and X-Robots-Tag. `/robots.txt` returns `Disallow: /`; `/sitemap.xml` returns 404. This matches the deliberate preview configuration documented in the project; it must be reconsidered when an indexable production site is authorized. Removing only one layer will not resolve the other restrictions. PageSpeed's failed SEO audit is indexing access; nine other SEO audits passed.
2. P2 local business accuracy: the visible/schema address is 634 S 9th Ave, Walla Walla, WA 99362, while the client-requested map CID 17343372594423126593 / coordinates 37.723875,-121.941944 refer to the previously supplied San Ramon reference listing. The map appears in `hasMap` and the site's Google link. Confirm the intended salon listing before changing it; schema validation cannot detect this factual discrepancy.
3. P2 mobile performance: home hero photo is the LCP element. PageSpeed measured LCP 5.9 s on simulated slow mobile. Its breakdown flags render delay (830 ms in the unthrottled breakdown) in addition to resource loading; inspect hero animation/paint timing and appropriate responsive delivery before attributing this only to file size. The lab LCP and breakdown timings use different throttling contexts and should not be added together.
4. P2 readability: PageSpeed flags insufficient contrast on the header Contact to Book CTA, both Show More buttons, and copyright strip. Adjust the foreground/background combination while preserving the gold palette, then remeasure.
5. P3 delivery: PageSpeed estimates 32 KiB image savings and 12 KiB cache-policy savings on mobile. The 234 KiB unused-JavaScript estimate is from Google Maps scripts (about 415 KiB total), rather than the site's small interaction bundle. Consider a deferred map activation while preserving a usable map link; do not assume that unused third-party code can be removed from Google's bundle.
6. P3 content: service prices contain six intentional pending placeholders. They are awaiting the owner's prices, not a crawler failure. Gallery alt text is present but generic; more specific descriptions of actual nail designs and salon-specific original content would improve usefulness. There is no automatic minimum-word-count requirement established by this audit.

## Direct production checks

Fetched all five routes: `/`, `/about-us`, `/services`, `/gallery`, `/contact-us`. All returned 200, unique nonempty titles/descriptions, correct HTTPS canonical, `lang=en`, one H1, and valid JSON-LD. No image omitted the alt attribute; decorative banner images legitimately have empty alt. All five reference the same share-image URL. `/services/` resolves to `/services`; a random nonexistent path returns a real 404.

Title lengths: 40–57 characters. Description lengths: 75–121 characters. Length alone is not treated as a ranking error.

Machine-readable live evidence: `test-results/seo-live-audit-2026-11-04.json` (local ignored artifact).

The Laravel CLI SEO audit was attempted with PHP 8.5.12 but could not connect to the stopped local MySQL instance; it is NOT marked passed for this run. Production HTML and external validators were inspected independently. No Search Console ownership/indexing data or backlink/rank audit was available in this check.

## Suggested sequence

Confirm correct Google business listing and final public domain; prepare production crawl/indexing policy plus sitemap; improve mobile hero rendering and CTA contrast; retest PageSpeed/schema on the official domain. Connect the owner's Search Console only when that launch is authorized. Preserve noindex while the site remains a preview.
